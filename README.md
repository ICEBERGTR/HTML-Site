# Personal Portfolio Website

Welcome to the repository for my personal portfolio and landing page! This website serves as a digital hub to showcase my background, technical skills, and software projects as a Software Engineering undergraduate.

## Features

- **About Me:** Quick introduction covering my academic background (Software Engineering at the University of Guelph, minor in Neuroscience, and Business certificate).
- **Tech Stack & Skills:** Overview of the programming languages, frameworks, and developer tools I work with.
- **Projects Showcase:** Direct links and highlights featuring my key projects (such as WardFit, Budgetly, Linux Process Manager, and IoT systems).
- **Contact & Links:** Professional links to get in touch or view my other profiles.
